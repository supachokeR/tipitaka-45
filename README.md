# สารานุกรมพระไตรปิฎก อรรถกถา ฎีกา ๔๕ เล่ม

สรุปโครงสร้าง แก่นธรรม ความเชื่อมโยง ๓ ชั้นคัมภีร์ (พระไตรปิฎก → อรรถกถา → ฎีกา) และวิเคราะห์ 5W1H ทีละเล่ม พร้อมระบบอ่านออกเสียง

**เปิดใช้งาน:** <https://supachoker.github.io/tipitaka-45/>

## เนื้อหา

| ส่วน | รายละเอียด |
|---|---|
| บทนำ | โครงสร้าง ๓ ชั้นคัมภีร์ + 5W1H ภาพรวมทั้ง ๔๕ เล่ม |
| พระไตรปิฎก ๔๕ เล่ม | แต่ละเล่มมี แก่น • ชั้นพระไตรปิฎก • อรรถกถา • ฎีกา • ใคร/ทำอะไร/ที่ไหน/เมื่อไร/อย่างไร/ทำไม • เรื่องเล่า ๒๕๑ เรื่อง (เนื้อเรื่อง + อรรถาธิบาย) |
| ดัชนีพระอริยบุคคล | ภิกษุ ๒๐ • ภิกษุณี ๑๐ • อุบาสก ๑๐ • อุบาสิกา ๑๐ — ประวัติ เอตทัคคะ ภูมิธรรม พระสูตรเอก และลิงก์ไปยังเล่มที่ปรากฏ |
| เครื่องมือศึกษา | ดัชนีหลักธรรม & ปัญหาชีวิต ๑๔ หัวข้อ • พุทธสถาน ๗ แห่ง • พุทธพจน์สุ่ม ๓๒๘ บท (บาลี–ไทย) • คลังของฉัน (bookmark) |

## ฟีเจอร์

- อ่านออกเสียง (Web Speech API) — อ่านต่อเนื่องทุกเล่ม / ทีละเล่ม / ทีละเรื่อง, เล่มก่อน–ถัดไป, หยุด/พัก, ความเร็ว 1–2x, เลือกเสียง, ไฮไลต์ประโยคที่กำลังอ่าน
- ฟัง/อ่านต่อจากจุดล่าสุด (resume)
- ค้นหาเนื้อหา, ค้นหาบุคคล, กรองตามปิฎก, ขยาย/ยุบทุกเล่ม
- สารบัญแบบ drawer, ปรับขนาดตัวอักษร, ธีม ๓ แบบ (ปกติ • ใบลาน • สว่าง)
- บันทึกค่าใน `localStorage`: bookmark, ฟอนต์, ธีม, จุดที่ฟังล่าสุด

## โครงสร้างไฟล์

```
index.html          หน้าเว็บ + logic ทั้งหมด (UI, TTS, ค้นหา, สารบัญ)
data/volumes.js     volumesData — ข้อมูล ๔๕ เล่ม + เรื่องเล่า
data/persons.js     noblePersonsIndexData — ดัชนีบุคคล ๕๐ ท่าน
data/study.js       dhammaTopics, placesData — เครื่องมือศึกษา
```

ไม่มี dependency ภายนอก เปิดไฟล์ `index.html` ตรงๆ หรือ serve ด้วย static server ใดก็ได้

## การแก้ไขข้อมูล

- **เพิ่ม/แก้เนื้อหาเล่ม** — แก้ใน `data/volumes.js` ตามโครงสร้างแต่ละ object (`vol, pitaka, pitakaName, title, subGroup, core, tipitakaLayer, atthakatha, tika, who, what, where, when, how, why, stories[]`)
- **เพิ่มพุทธพจน์** — แทรกในข้อความ `narrative` หรือ `commentary` ด้วยรูปแบบ `⟪บาลี || คำแปลไทย⟫` ระบบจะดึงเข้าคลังพุทธพจน์สุ่มอัตโนมัติ
- **เพิ่มบุคคล** — เพิ่ม object ใน `data/persons.js` (`category` เป็น `bhikkhu | bhikkhuni | upasaka | upasika`, `volumes` คือเลขเล่มที่ปรากฏ, `searchKeyword` ใช้ค้นในเนื้อหา)
- **เพิ่มหัวข้อธรรม/สถานที่** — แก้ `data/study.js`
